# Analisis Pengaruh Cuaca terhadap Pendapatan dan Jumlah Order Gojek Tahun 2023

## Deskripsi Proyek

Proyek ini menganalisis hubungan antara kondisi cuaca dengan pendapatan harian dan jumlah order Gojek selama tahun 2023. Analisis dilakukan menggunakan Microsoft Excel melalui tabel data harian, PivotTable, PivotChart, dan dashboard interaktif.

Tujuan utama proyek adalah mengetahui apakah kondisi cuaca seperti hujan, cerah, dan berawan memiliki hubungan dengan perubahan pendapatan harian serta jumlah order.

## Pertanyaan Analisis

1. Apakah kondisi cuaca memengaruhi rata-rata pendapatan harian?
2. Apakah kondisi cuaca memengaruhi rata-rata jumlah order?
3. Bagaimana perubahan pendapatan dan jumlah order setiap bulan?
4. Apakah jam online juga berhubungan dengan pendapatan harian?

## Struktur Data

Dataset menggunakan data harian dengan kolom berikut:

| Kolom | Keterangan |
|---|---|
| Tanggal | Tanggal transaksi |
| Hari | Nama hari |
| Bulan | Nama bulan |
| Kondisi Cuaca | Cuaca harian, seperti Hujan, Cerah, atau Berawan |
| Jam Online | Lama waktu pengemudi aktif dalam satu hari |
| Jumlah Order | Jumlah pesanan per hari |
| Pendapatan Harian | Total pendapatan harian dalam Rupiah |

## Analisis yang Dilakukan

Proyek ini menggunakan beberapa PivotTable:

1. Rata-rata pendapatan harian berdasarkan kondisi cuaca.
2. Rata-rata jumlah order berdasarkan kondisi cuaca.
3. Rata-rata pendapatan berdasarkan bulan dan kondisi cuaca.
4. Rata-rata jumlah order berdasarkan hari dan kondisi cuaca.
5. Rata-rata jam online, jumlah order, dan pendapatan berdasarkan kondisi cuaca.
6. Ringkasan total pendapatan, total order, dan rata-rata jam online setiap bulan.

## Visualisasi Dashboard

Dashboard terdiri dari:

- Diagram batang pendapatan berdasarkan kondisi cuaca.
- Diagram batang jumlah order berdasarkan kondisi cuaca.

- Grafik garis total jumlah order per bulan.

## Tools yang Digunakan

- Microsoft Excel

## Catatan Data

Data pendapatan bulanan bersumber dari laporan pendapatan tahun 2023. Data kemudian disusun dalam bentuk harian untuk kebutuhan analisis.

Kondisi cuaca diinput secara manual. Jika jumlah order dan jam online tidak berasal dari catatan operasional asli, kedua data tersebut digunakan sebagai estimasi. Oleh karena itu, hasil analisis menunjukkan hubungan pada dataset yang digunakan dan tidak membuktikan bahwa cuaca adalah satu-satunya penyebab perubahan pendapatan atau jumlah order.

## Kesimpulan

Berdasarkan dashboard, kondisi cuaca dapat dibandingkan dengan rata-rata pendapatan harian dan jumlah order. Hasil akhir perlu disesuaikan dengan angka pada grafik yang telah dibuat. Selain kondisi cuaca, jam online, hari kerja, akhir pekan, dan faktor lainnya juga dapat memengaruhi pendapatan serta jumlah order.
